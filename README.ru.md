# Creative SXFI GAMER: управление самопрослушиванием

**Микрофон работает, а собственный голос в наушниках можно отключить.**
Неофициальная модификация прошивки **2.07.02** для **Creative SXFI GAMER EF0880**.
Кнопка микрофона переключает три состояния:

| Нажатие | Сообщение | Микрофон | Самопрослушивание |
|---|---|---|---|
| Первое | Mic on | Работает | Выключено |
| Второе | Mic on | Работает | Включено |
| Третье | Mic off | Отключён гарнитурой | Выключено |

Затем цикл повторяется. Состояние сразу после подачи питания остаётся заводским.
Первое допустимое нажатие выбирает **микрофон включён / самопрослушивание выключено**.
Выбранное состояние между отключениями питания не сохраняется.

**[Скачать готовый комплект для Windows](https://github.com/Brian444github/sxfi-gamer-sidetone/releases/download/v2.07.02-three-state-r1/SXFI_GAMER_2.07.02_three-state-r1_Windows.zip)**

Для установки не нужны Python, компилятор или отдельное скачивание заводской
прошивки. Скачивайте архив релиза по ссылке выше. **Code → Download ZIP** на
GitHub скачивает исходники.

## Как установить

1. Проверьте маркировку: **SXFI GAMER / EF0880**. Для SXFI AIR, AIR C и AIR GAMER
   этот комплект не подходит.
2. Скачайте архив релиза и распакуйте его в обычную локальную папку Windows.
3. Отключите USB наушников. Зажмите **кнопку RGB-подсветки**, подключите USB,
   продолжайте держать примерно **пять секунд**, затем отпустите. Нужна кнопка
   подсветки, не Super X-Fi. В recovery звуковые устройства наушников исчезают —
   это ожидаемое поведение.
4. Запустите **`INSTALL-r1.cmd`**. Он проверит контрольную сумму и откроет родной
   обновлятор с параметром `/F`. Само обновление запускается кнопкой в окне.
5. Убедитесь, что выбрана нужная гарнитура, нажмите **Upgrade**. Не отключайте USB
   до сообщения **“Upgrade is successful.”** Затем закройте обновлятор.
6. Проверьте три состояния кнопки микрофона и сделайте запись в обоих состояниях
   Mic on.

**[Полная инструкция: установка, сообщения Windows, проблемы и возврат заводской прошивки](docs/INSTALL.ru.md).**

## Проверка и ограничения

Точная сборка r1 успешно установлена на **одну реальную EF0880 через Windows 11**.
Владелец проверил запись с выключенным самопрослушиванием, запись с включённым
самопрослушиванием и отключение микрофона третьим нажатием. Вход в recovery
кнопкой RGB и возвращение к обычному режиму переподключением USB также проверены.

Это неофициальный релиз с ограниченной аппаратной проверкой. Другие ревизии,
операционные системы, все звуковые режимы и длительное поведение после
переподключений/сбросов не проверены. Заводской установщик включён в архив,
порядок возврата описан, но фактический откат на заводскую прошивку ещё не
проверялся. Прерывание прошивки или применение к несовместимой модели может
привести к неработоспособности устройства.

Модифицированный установщик **не имеет цифровой подписи**. Его исполняемый код и
все ресурсы, кроме встроенного образа прошивки, совпадают с заводским.
[Результаты проверки](docs/VALIDATION.md), [техническое описание](docs/TECHNICAL.md),
[компоненты Creative](THIRD_PARTY.md).

Версия в устройстве остаётся `2.07.02 (81C80082)`: по одной этой строке r1 не
отличить. Ориентируйтесь на контрольные суммы и работу трёх состояний кнопки.
