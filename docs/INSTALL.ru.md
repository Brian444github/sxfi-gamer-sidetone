# Установка r1 для Creative SXFI GAMER EF0880

## 1. Подготовка

Поддерживаемая цель этого релиза — **Creative SXFI GAMER, модель EF0880**, USB
VID/PID `041E:3269`. Проверьте маркировку самой гарнитуры. Один USB ID не заменяет
проверку модели. SXFI AIR, AIR C и AIR GAMER — другие устройства.

Установка проверена на Windows 11. Установщик для Windows уже содержит образ
прошивки. Python, сборка исходников и установка SXFI Control для описанного
процесса не нужны. На других версиях Windows этот комплект отдельно не проверен.

1. Скачайте **`SXFI_GAMER_2.07.02_three-state-r1_Windows.zip`** из GitHub Releases:
   <https://github.com/Brian444github/sxfi-gamer-sidetone/releases/tag/v2.07.02-three-state-r1>.
2. Распакуйте **весь** архив в локальную папку. Не запускайте файлы прямо из ZIP.
3. Закройте программы, использующие микрофон/наушники, и другие обновляторы
   Creative. Подключите гарнитуру напрямую к исправному USB-порту. Если таких
   гарнитур несколько, оставьте подключённой только целевую.
4. На время обновления обеспечьте питание компьютера и не допускайте его сна.
   Не отключайте кабель и не перезагружайте компьютер во время записи прошивки.

Модифицированный EXE не подписан Creative. Windows может показать предупреждение
о неизвестном издателе или SmartScreen. Проверьте источник и SHA-256. Если Windows
предлагает «Подробнее → Выполнить в любом случае», используйте это только для
проверенного файла. Если политика компьютера запрещает запуск, остановитесь;
отключать защиту Windows для установки не требуется.

## 2. Вход в recovery

1. Отключите USB-кабель наушников от компьютера.
2. Нажмите и удерживайте **кнопку RGB-подсветки** на гарнитуре.
3. Удерживая кнопку, снова подключите USB.
4. Продолжайте держать кнопку примерно **пять секунд**, затем отпустите.

Это кнопка подсветки, **не Super X-Fi** и не кнопка микрофона. Этот способ
проверен на тестовой EF0880. В recovery наушники временно не воспроизводят и не
записывают звук. Windows видит интерфейсы HID и последовательного устройства;
номер COM-порта зависит от компьютера. Отсутствие звукового устройства в этом
режиме ожидаемо.

Чтобы выйти из recovery без прошивки, отключите и снова подключите USB,
не удерживая кнопок. Этот выход также проверен.

## 3. Установка

1. Откройте распакованную папку и запустите **`INSTALL-r1.cmd`**.
2. Файл запуска проверит SHA-256 установщика. При несовпадении он остановится.
3. Откроется родной обновлятор Creative со встроенной r1. Параметр `/F` уже
   передан: он разрешает обновление с той же заводской версией 2.07.02.
4. Убедитесь, что обновлятор обнаружил гарнитуру и кнопка **Upgrade** доступна.
   При отсутствии устройства переходите к разделу устранения проблем.
5. Нажмите **Upgrade** один раз. Дождитесь окончания. Во время сообщения
   **“Upgrading in progress...”** не закрывайте программу и не отключайте USB.
6. Дождитесь **“Upgrade is successful.”** Затем закройте обновлятор. Гарнитура
   должна вернуться в обычный USB-аудиорежим. Если после успешного завершения
   Windows ещё не обновила устройства, переподключите USB без нажатия кнопок.

Запасной ручной запуск из PowerShell в папке комплекта:

```powershell
& '.\SXFI_GAMER_2.07.02_three-state-r1.exe' /F
```

Перед ручным запуском проверьте хеш по разделу ниже. Не добавляйте `/S` или `/B`:
комплект рассчитан на обычное окно обновлятора и обновление основной прошивки.

## 4. Проверка результата

Отключите программное прослушивание микрофона в Windows и тестах голосовых
приложений, чтобы оно не накладывалось на внутреннее самопрослушивание гарнитуры.
В Windows проверьте свойства микрофона → «Прослушать» → «Прослушивать с данного
устройства»: для проверки эта опция должна быть выключена.

После первого допустимого нажатия кнопки микрофона:

1. **Mic on:** себя в наушниках не слышно, но запись голоса работает. Сделайте
   короткую запись и прослушайте её после завершения записи.
2. **Mic on:** себя в наушниках слышно, запись продолжает работать.
3. **Mic off:** микрофон отключён самой гарнитурой, голос в новую запись не
   поступает. Включение микрофона в Windows не отменяет этот mute гарнитуры.

Дальше цикл повторяется. После подачи питания начальное состояние остаётся
заводским; r1 не делает самопрослушивание автоматически выключенным при старте.
Первое допустимое нажатие выбирает Mic on без самопрослушивания. Выбранное
состояние не сохраняется при отключении питания.

Устройство продолжает сообщать `2.07.02 (81C80082)`. Это ожидаемо: строка версии
не является признаком успешной установки r1. Проверяйте реальное поведение кнопки.

## 5. Если что-то не получилось

- **Windows не видит звук после входа в recovery:** это ожидаемо. Нужен обновлятор.
- **Обновлятор не обнаружил гарнитуру или Upgrade недоступна:** если запись
  прошивки не идёт, закройте обновлятор, повторите вход через кнопку RGB и запуск
  `INSTALL-r1.cmd`. Проверьте USB-кабель и прямой порт, дождитесь установки
  стандартных устройств Windows. Не меняйте драйвер через Zadig и не назначайте
  случайный COM-порт. Если не помогло — сохраните точное сообщение и создайте Issue.
- **Хеш не совпал:** остановитесь и скачайте релиз заново из этого репозитория.
- **Появилось сообщение об ошибке обновления:** запишите его. Не запускайте
  несколько обновляторов одновременно. При незавершённой операции не считайте
  отсутствие звука доказательством поломки и не прерывайте текущую запись.
- **Не различаются первые два состояния:** проверьте, что выключено программное
  прослушивание. Затем проверьте запись и цикл ещё раз. Приложите результат к Issue.

Вход в recovery аппаратной кнопкой проверен на рабочей гарнитуре. Восстановление
после произвольного повреждения или прерванной записи не проверялось; гарантии
восстановления любого сбоя нет.

## 6. Возврат к заводской прошивке

В комплекте лежит **неизменённый** заводской установщик 2.07.02. Описанный ниже
порядок использует тот же режим обновления, но **фактический откат с r1 на заводскую
прошивку пока не проверен**.

1. Введите гарнитуру в recovery кнопкой RGB, как описано выше.
2. Запустите **`RESTORE-factory.cmd`**. Он проверит заводской EXE и откроет его с `/F`.
3. Убедитесь, что обнаружено нужное устройство, нажмите Upgrade и дождитесь
   “Upgrade is successful.” Не отключайте USB во время записи.
4. Закройте программу и проверьте заводскую работу микрофона.

Ручной эквивалент после проверки хеша:

```powershell
& '.\SXFI_GAMER_2.07.02_FACTORY.exe' /F
```

## 7. Контрольные суммы

В PowerShell из папки комплекта:

```powershell
Get-FileHash '.\SXFI_GAMER_2.07.02_three-state-r1.exe' -Algorithm SHA256
Get-FileHash '.\SXFI_GAMER_2.07.02_FACTORY.exe' -Algorithm SHA256
```

Ожидаемые SHA-256:

```text
82d96a46f4e43233f0a983ecd06ba10ee73612c46d30afc5a9061c5e60ac6adb  SXFI_GAMER_2.07.02_three-state-r1.exe
1e451307c07e6ea643ed5f88eb4e7e074f985f6b740adea219940ce596965496  SXFI_GAMER_2.07.02_FACTORY.exe
```

Для самого ZIP контрольная сумма опубликована отдельным файлом в GitHub Release.
SHA-256 подтверждает совпадение байтов с опубликованным релизом, а не цифровую
подпись производителя и не совместимость с любой гарнитурой.
